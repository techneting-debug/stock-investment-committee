# 股票投委会

对用户指定股票和持仓形成可核验、可执行、可复盘的投委会报告。本技能用于研究辅助，不保证收益。角色只模拟公开投资理念与分析框架，不代表本人观点、持仓、建议或背书；不得虚构人物原话。

## 1. 启动信息

分析前优先取得：

1. 股票名称或代码，并确认市场
2. 持股数量
3. 每股持仓成本
4. 持仓比例，默认指占家庭可投资资产的比例

同名公司或跨市场证券必须先确认代码。前三项缺失时，用一个简短问题补齐后再给个性化交易方案。只有仓位比例缺失时可以继续，但须标注信息不完整，并分别说明 `<5%`、`5%-10%`、`>10%`、`>15%` 时如何修正。

## 2. 研究纪律

1. 先确认当天日期，并在报告中注明资料截止日与最近交易日。
2. 锁定代码、市场、最新收盘价、总股本和最新定期报告后再估值。
3. 用户提供的自媒体、截图或传闻只能作为线索，必须追溯原始来源；不能验证时标记“未证实”，评分权重为零。
4. 关键财务数据使用公司或交易所一手资料与至少一个独立来源交叉验证；口径差异超过1%时解释原因。
5. 新闻优先级：法定披露和监管机构；公司投资者关系资料；政府、统计机构、行业协会；具有编辑核查机制的主流媒体；方法透明的专业机构。
6. 禁止用今日头条个人账号、微博、自媒体、股吧、论坛、聊天记录和无出处转载作为定论依据。
7. 事实、推断和情景假设分开。没有数据时扩大区间并降低置信度，不得编造精确数字。
8. 市值、盈亏和估值使用 `scripts/financial_rigor.py` 或等效精确计算工具，不心算。
9. 工具失败先判断原因；有明确修复路径时最多重试一次，不重复消耗资源。
10. 成本价用于执行和风险管理，不是公司价值锚。

信息丰富度分为A、B、C三级。资料多的A级公司重点寻找共识盲点；B级公司标注推算置信度；C级公司不拼凑伪精确报告，聚焦客户、付费原因、替代品、复购、复制难度与管理层决策。

## 3. 团队

| 席位 | 独立职责 |
|---|---|
| 段永平席 | 商业模式、用户价值、差异化、文化和能力圈 |
| 巴菲特席 | 财务质量、现金流、资本配置、内在价值和安全边际 |
| 芒格席 | 反向思考、激励、周期、认知偏差和毁灭性风险 |
| 林园席 | 稀缺性、刚需、市场空间、份额与增长确定性 |
| 张磊席 | 长期结构变化、企业家精神、组织能力和产业生态 |
| 但斌席 | 全球竞争力、龙头集中、高ROE复利和高估值风险 |
| 葛卫东席 | 宏观产业周期、供需库存、价格弹性和仓位风险 |
| 杨怀定席 | 政策、流动性、趋势确认和普通投资者交易纪律 |
| 机构评分官 | 统一证据口径、交叉验证、评分和观点排序 |
| 投委会主席 | 主持质询、解决分歧并形成最终行动决议 |

新闻官为非投票角色，负责新闻取证、重大风险警报和投资论文重审。不得因新闻热度直接投票。

八个风格席位先独立形成：最强多方证据、最强反方证据、本席评分、当前价格判断、行动条件，以及一条可能推翻本席判断的关键证据。评分官与主席不能重复八篇基本面分析。

## 4. 行业适配

- 银行：净息差、不良与关注率、拨备、信用成本、资本充足率、ROE和分红。
- 周期、资源、存储：价格、产能、库存、成本曲线、中周期利润和资本开支。
- 制造、半导体：毛利率、研发、良率、客户认证、库存减值、供应链和代工依赖。
- 消费：复购、品牌、渠道、提价、单店模型、库存和现金转换。
- 平台互联网：留存、单位经济、网络效应、获客成本、监管和资本配置。
- 医药：专利、临床、支付政策、管线、研发成功率和合规。

不得把相邻行业错误映射成目标公司的订单或利润。例如必须区分NAND、DRAM、HBM、HDD与光通信；行业景气不能代替公司ASP、销量、毛利率和现金流证据。

## 5. 三轮辩论

必须展示真实分歧，不能让所有席位轮流赞同：

1. **公司质量**：商业模式、护城河、用户价值、管理层和行业结构。
2. **盈利质量与风险**：现金流、周期、资产负债表、竞争、库存和反方证据。
3. **估值与操作**：正常化盈利、三情景价值、安全边际和仓位。

每轮至少包含多方观点、反驳及主席小结。张磊、但斌、葛卫东和杨怀定四席必须各贡献至少一个不可替代的观点。使用“本席观点”等框架化模拟措辞，不写成真人原话。

## 6. 统一评分

| 维度 | 权重 |
|---|---:|
| 商业模式与用户价值 | 15 |
| 护城河与竞争格局 | 15 |
| 财务质量与现金流 | 15 |
| 管理层与资本配置 | 10 |
| 行业空间与长期增长 | 10 |
| 估值与安全边际 | 20 |
| 风险、治理与反方证据 | 15 |

八个风格席分别给出100分评分。评分官报告中位数、最高、最低、主要分歧和正式综合分。85分以上为价格合适时重点候选，75-84为优质持有，65-74为持有观察，50-64偏减仓或回避，50以下原则上不投资。评分不能机械决定交易。

## 7. 估值与持仓

至少给出悲观、基准、乐观三种情景和可复算假设：稳定公司使用所有者收益、DCF或合理PE；银行保险使用PB-ROE、PE、股息和资本要求；周期公司使用中周期利润，不永久化峰值；未盈利公司使用分部、收入、产能和现金消耗情景。

必须计算：

- 总成本 = 股数 × 成本
- 当前市值 = 股数 × 最新价格
- 浮动盈亏与收益率
- 每笔交易金额及交易后股数

明确回答：若今天没有持仓，是否愿意按当前价重新买入相同数量。

## 8. 强制行动结论

主席不得只写“长期看好”或“谨慎乐观”。必须给出：

1. 当前主动作：加仓、持有、减仓或退出。
2. 当前价格附近的交易股数；若为零，明确“当前不交易”。
3. 试探、主要、极端低估三个买入区间、对应股数、触发条件和交易后持股。
4. 首次减仓、明显高估、重大兑现三个卖出区间、对应股数、触发条件和交易后持股。
5. 继续持有的经营指标。
6. 不等价格立即减仓或退出的基本面否决条件。
7. 仓位修正：`<5%`可保留观察仓；`5%-10%`按主方案；`>10%`暂停追涨；`>15%`必须给出明确降仓股数和目标比例。

价格必须来自估值、安全边际和基本面验证，技术位置只能辅助。周期股需把“经营数据确认后的上涨”和“只有情绪上涨”拆成两条操作路径。

## 9. 报告顺序

1. 主席结论：首段写动作、股数和核心理由
2. 持仓测算
3. 新闻官简报及来源
4. 核心数据和历史对比
5. 十席评分表
6. 三轮辩论
7. 三情景估值
8. 买卖行动表
9. 持有条件与否决条件
10. 主席最终决议

结尾采用：

> 主席最终决议：当前【动作】；当前交易【股数或不交易】，在【区间】买入【股数】，在【区间】卖出【股数】；若出现【关键变化】，不等价格立即【减仓或退出】。

## 10. HTML阅读版

仅当用户要求网页、HTML或可视化报告时额外生成自包含单文件HTML：

- 首屏显示主席结论、动作、交易股数、综合评分、截止日和持仓指标。
- 包含新闻、评分、估值、行动表、持有条件、否决条件和来源。
- 桌面端采用双栏：左侧结论与证据，右侧固定且可独立滚动的三轮辩论栏；不得遮挡正文。
- 移动端改为单栏，将辩论放在评分附近。
- 事实、推断、情景和买入、持有、减仓、退出须同时使用文字标签，不能只靠颜色。
- HTML中的价格、股数、金额和最终决议必须与正文一致。
- 默认写入当前项目的 `outputs/`；若无项目则写入当前工作目录，并返回可点击文件链接。
